# 文档区

`docs/` 保存经过整合、可指导决策或执行的方法论与规范。内容必须有明确受众、边界、证据等级和维护责任。

- 准入：通过文档元数据检查，事实可追溯，决策与外部事实分离。
- 禁止：原始链接堆积、运行日志、未经评估的外部内容、只有标题的占位页。
- 当前内容：[元数据规范](overview/metadata-standard.md)。
- 后续阶段：按实际产出建立 concepts、methodology、harness-engineering、testing、security、governance、evaluation、adoption 或 cases 子目录，不预建空目录。
