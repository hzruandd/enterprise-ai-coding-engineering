# Examples 区

`examples/` 保存从真实、非生产试点中提炼并去敏的端到端案例，帮助团队复现采用路径。

- 准入：需求、环境、步骤、Gate、失败与结果完整，敏感信息已移除，许可证明确。
- 禁止：虚构成功案例、只有 happy path 的 Demo、生产数据或密钥、未经验证的外部代码。
- 当前阶段：没有案例；Phase 0–1 不用空样例制造完成度。
- 后续阶段：Phase 5 试点验收后形成案例，并链接对应 Eval、Trace 摘要和资产版本。
